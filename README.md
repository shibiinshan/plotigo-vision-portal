# Plotigo Premium

Build a premium, modern and highly conversion-focused real estate website for "Plotigo.in", a Kerala-based real estate developer/property platform.

IMPORTANT:

Use the uploaded Plotigo Instagram screenshots as the visual branding reference.

Brand identity:

- Brand: Plotigo

- Logo: Plotigo black square speech/plot icon with small yellow/gold square

- Primary colors: Black #080B12, Lime Green #A8C63A, White #FFFFFF

- Secondary accent: Warm Gold #D6A928

- Background: #FAFAF7

- Typography: modern bold sans-serif, similar to Inter/Poppins

- Visual style: premium, minimal, architectural, trustworthy

- Do NOT make it look like a generic real estate template.

- Maintain the visual language from the Instagram posts: architectural line drawings, subtle grids, maps, property imagery and lime-green typography.

GOAL:

Create a high-converting real estate website that turns visitors into WhatsApp enquiries and property leads.
